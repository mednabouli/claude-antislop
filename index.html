Features

Everything You Need to Catch AI Slop

Comprehensive detection rules and seamless integrations to keep your codebase clean and professional.

🔍

Pattern Detection

Identifies placeholder comments, lazy naming, copy-paste artifacts, and hallucinated imports automatically with 50+ detection rules.

🛠️

Multi-Modal Integration

CLI, GitHub Actions, MCP server, VS Code extension, and watch mode for real-time feedback wherever you code.

📝

Configurable Rules

Customize detection sensitivity via `.antisloprc` or CLI flags to match your team's coding standards perfectly.

🔒

Security-First

Built-in security audit checks for exposed secrets, unsafe patterns, SQL injection, XSS, and weak cryptography.

🌐

Localization Support

Detect non-English comments and strings that slip through AI generation, ensuring consistent code documentation.

📊

JSON Output

Machine-readable reports for CI/CD pipelines, custom dashboards, and automation tooling integration.
