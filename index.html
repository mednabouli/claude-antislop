A local quality loop

Use the project history and your own stored standards to guide decisions without centralizing private development data.

1. Capture what mattersStore standards and recurring lessons in structured memory categories.
2. Check before shippingValidate formatting, linting, and types from one focused interface.
3. Learn from the codebaseScan repositories and analyze history to surface real conventions and trends.
# Find an established standard
claude-antislop memory-search \
  --query "TypeScript strict mode" \
  --category standards

# Validate a focused code snippet
claude-antislop code-quality-check \
  --language typescript \
  --checks lint,typecheck,prettier

# Learn from recent project work
claude-antislop learn-from-git --recent 30d

Start locally

Clone the repository, install dependencies, and initialize personal memory when you are ready. The exact command surface should be treated as the repository implementation evolves.

# Clone and install

npx claude-antislop --help
